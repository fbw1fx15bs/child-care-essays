# 子宫内膜炎的症状是什么？可以做试管婴儿吗？

> 更新时间：2026-09-17 (UTC+8)

子宫内膜炎是女性生殖系统的一种炎症性疾病，主要影响子宫内部的黏膜层——子宫内膜。这种疾病不仅对女性健康产生负面影响，而且可能影响到她们的生育能力。因此，了解其症状以及它对辅助生殖技术（如试管婴儿）的影响至关重要。
**子宫内膜炎的症状**
子宫内膜炎的症状可能轻微至严重不等，有时甚至没有明显的症状。然而，常见的症状包括：

1. **异常阴道分泌物**：可能出现异味、颜色或质地的变化。

2. **下腹部疼痛**：尤其是在月经期间或性交后更为明显。

3. **月经周期变化**：包括经血量增加或减少、痛经加剧等。

4. **发热和疲劳**：在感染较为严重时可能出现。

5. **性交痛**：由于炎症的存在，在进行性活动时可能会感到不适或疼痛。
**可以做试管婴儿吗？**
对于患有子宫内膜炎的女性来说，是否能够进行试管婴儿（IVF）取决于多个因素，包括病情的严重程度、治疗效果及个人的整体健康状况。
